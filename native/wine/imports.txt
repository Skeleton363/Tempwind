# The wasm imports Wine's Unix side may have (docs/design/wine-unix.md,
# section 2, gate 2). One import per line: `module.field`, then its reason.
# build.sh fails on any import of any module built (wine-unix and the test
# modules) that isn't listed here. A new import needs its line, with a
# reason, in the same change. Lines may list imports a module doesn't have
# (yet): the gate checks module ⊆ list.
